# Two Engine Go-Around

* ==TOGA, power, pitch==
  * Press GA button
  * T/O thrust
  * Pitch to 12-15&#176; nose up
* ==PF calls "go around, flaps 8&#176;"==
* ==PM calls "positive rate"==
  * ==PF calls "gear up"==
* ==PF calls for speed mode==
  * "speed mode, bug V2 + 20"
  * Recall, V2 bug indicates VAPP (approach climb speed)
* ==PF calls for source and mode as necessary==
  * See [Calling for Source and Mode](#calling-for-source-and-mode)
* ==PM calls "flap safety speed"==
  * i.e. VAPP + 20
  * ==PF calls "flaps up"==
* PF calls for autopilot on
* Reduce thrust as needed to level off according to missed approach procedure / instructions
* ==***PF calls for go-around checklist***==
